# Joy-Ride-
Joy Ride is a hyper-localized mobility and ad-reward web application for students and commuters in Ile-Ife, Nigeria. It connects riders off-campus :Mayfair, Lagere, and Asherifa to the OAU Campus Gate, using okada bookings (₦500),etc  and an ad-supported "Watch &amp; Ride" system where users convert ad views into free trips and foodstuff rewards.
